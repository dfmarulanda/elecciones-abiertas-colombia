# Glossary / Glosario

| Term / Término                  | ES                                                                                                                       | EN                                                                                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| Mesa                            | Unidad de registro identificada por departamento, municipio, puesto y número de mesa.                                    | Reporting unit identified by department, municipality, polling place, and mesa number.                              |
| Puesto                          | Lugar de votación que agrupa mesas.                                                                                      | Polling place that groups mesas.                                                                                    |
| Preconteo                       | Capa preliminar e informativa; no jurídicamente vinculante.                                                              | Preliminary, informational layer; not legally binding.                                                              |
| Escrutinio                      | Resultado oficialmente publicado con validez jurídica solo en su ámbito y granularidad explícitos.                       | Officially published result, legally valid only at its explicit scope and grain.                                    |
| Declaración final               | Fuente controlante cuando una autoridad competente publica y verifica la declaración final aplicable.                    | Controlling source once a competent authority publishes and verification confirms the applicable final declaration. |
| E-14                            | Copia documental de delegados o transmisión; evidencia para revisión, no sustituto de la fuente oficial.                 | Delegate or transmission documentary copy; review evidence, not a substitute for the official source.               |
| Procedencia / provenance        | Metadatos que vinculan un hecho con versión de datos, capa, condición jurídica, URL, fecha, hash y versiones de proceso. | Metadata linking a fact to data version, layer, legal status, URL, time, hash, and process versions.                |
| Hash                            | Huella SHA-256 de contenido para comprobar una versión específica.                                                       | SHA-256 content fingerprint used to check a specific version.                                                       |
| Release inmutable               | Conjunto versionado que no se altera; una corrección crea otro release.                                                  | Versioned set that is not changed; a correction creates another release.                                            |
| `data_version`                  | Identificador del release inmutable consultado; si se omite, la API selecciona el release activo verificado.             | Identifier of the queried immutable release; when omitted, the API selects the active verified release.             |
| Cobertura                       | Conteos esperados, recuperados, analizados, faltantes, ambiguos y excluidos.                                             | Counts expected, retrieved, parsed, missing, ambiguous, and excluded.                                               |
| Cero observado                  | Valor `0` que la fuente reportó explícitamente.                                                                          | A `0` value explicitly reported by the source.                                                                      |
| Desconocido (`unknown`)         | No se conoce el valor; debe serializarse como `null`, no como cero.                                                      | Value is not known; it must serialize as `null`, not zero.                                                          |
| No disponible (`unavailable`)   | La fuente o publicación no permite disponer del valor; debe ser `null`, no cero.                                         | Source or publication does not make the value available; it must be `null`, not zero.                               |
| No aplicable (`not_applicable`) | La métrica no corresponde a ese hecho; debe ser `null`.                                                                  | Metric does not apply to that fact; it must be `null`.                                                              |
| Señal de revisión               | Componente explicable para ordenar revisión documental. No es una conclusión jurídica.                                   | Explainable component for ordering documentary review. It is not a legal conclusion.                                |
| Elegibilidad                    | Condiciones mínimas para ejecutar una prueba; no elegible no significa normal ni anómalo.                                | Minimum conditions to run a test; ineligible means neither normal nor anomalous.                                    |
| Derivado redactado              | Recorte público revisado de la región de votos; no reemplaza el original oficial.                                        | Public, reviewed crop of the vote region; it does not replace the official original.                                |
